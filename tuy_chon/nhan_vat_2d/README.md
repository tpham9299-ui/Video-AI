# Tùy chọn: nhân vật 2D dẫn chuyện

Đã làm và thử, **không dùng** trong bản chính vì bạn chọn video chỉ tập trung vào hình ảnh toán học. Mã giữ lại để dùng sau:
1. Chép `src/nhanvat2d` vào `src/`.
2. Nối `NhanVat2D` vào `Video.tsx` (nhận danh sách cảnh `CanhNV`, thư mục ảnh `public/nhan_vat`, cấu hình `phong_cach.json > nhanVat`).
3. Xem `HUONG_DAN_NHAN_VAT_2D.md` để chuẩn bị bộ ảnh.
